# 照片滤镜

喵墨 0.5.10 在「编辑照片 → 滤镜」中提供「经典四色」和「自然暖调」，选择随当前照片编辑记录保存。自然暖调为默认值，支持即时四色预览、撤销、重做和取消；点击「完成」才提交编辑。

<img src="images/editor-filters.png" width="300" alt="编辑照片的滤镜页，包含经典四色和自然暖调">

以上是当前源码的 Android 原生界面渲染，使用合成测试卡，未代表真实墨水屏刷新效果。

经典四色继续使用原有 `InkSightQuantizer` 增强与 Atkinson 算法。自然暖调由 `EinkWarmQuantizer` 独立实现，参考 [moink 固定提交](https://github.com/atunverse/moink/tree/081af81ec05c6a66f9fe6d5f598bcf229eff8723) 的 natural / std / Floyd–Steinberg 参数，误差扩散强度 0.85，查表幂次 1.75。未将其页面或上游实现打包进 App。

照片先量化，再叠加文字和相框；叠加层只映射到最近屏幕颜色，避免文字被照片误差扩散打散。整张已编码四色图直接保留编号，缩放使用最近邻；普通 RGB 照片保持原有高质量缩放。黑、白、黄、红对应 NFC 编号 0、1、2、3。

编辑器与 NFC 共用 `ImageCodec.prepareEdited` 的结果。横向照片先映射到屏幕物理方向，预览像素和 NFC 载荷保持一致，不改变原有列方向和 2bpp 打包。`PhotoEdit` v2 保存 `colorProfile`，兼容旧 v1 和原有 `scene_v1` 偏好键；缺少滤镜字段时默认自然暖调。

仅有四色文件时无法恢复原始 RGB，切换效果需要原图。四色屏也无法完整还原蓝、青等 RGB 色域，实物观感受屏幕批次影响。本次滤镜更新不改变既有 NFC 适配状态。

`tests/einkwarm-fixtures` 中的独立数学参考覆盖 37 张图、864445 个像素，包括别名四色、窄图、奇数尺寸、渐变和完整屏幕。原有经典参考保留。原生图形测试还检查两种效果的预览/载荷逐像素对应、文字和边框保护、编辑历史、取消、重启恢复及快速切换产生的过期预览。
